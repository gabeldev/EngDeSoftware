# Consulta de notas

Protótipo em Python para consulta segura de notas de alunos pelo terminal.

## Requisitos implementados
- R1: o aluno pode consultar suas notas.
- R2: somente usuários autenticados podem realizar a consulta.
- R3: um aluno não pode visualizar as notas de outro aluno.

Execute com `python3 main.py`.
